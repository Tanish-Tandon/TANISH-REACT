# 🍔 React Food Order Web App

A modern and responsive **food ordering web application** built using **React**.  
This project focuses on component-based architecture, performance optimization, and a clean user experience.

## 🚀 Features
- 📋 Browse food items and menu
- 🛒 Add / remove items from cart
- ⚡ Fast development & build using Parcel
- ♻️ Hot Module Replacement (HMR)
- 📱 Fully responsive UI
- 🧩 Reusable React components

## 🛠 Tech Stack
- **Frontend:** React, JavaScript, HTML, CSS
- **Styling:** Tailwind CSS
- **Bundler:** Parcel

## ⚙️ Parcel Highlights
- Local development server
- Hot Module Replacement (HMR)
- File watching algorithm (written in C++)
- Faster builds with caching
- Image optimization & minification
- Bundling & compression
- Tree shaking (removes unused code)
- Code splitting
- Differential bundling (supports older browsers)
- Separate development & production builds
- Error handling & diagnostics
- HTTPS support

## 📌 Learning Outcomes
- Strong understanding of React fundamentals
- Component-based UI design
- Optimized build process using modern tooling
- Practical experience with real-world frontend workflow
